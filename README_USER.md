# 简历评估系统 — 使用指南

## 第一次使用（只需做一次）

### 1. 解压
把收到的 ZIP 文件解压到桌面或任意文件夹。

### 2. 双击启动
- **Mac**：双击 `简历评估.app`
- **Windows**：双击 `简历评估.exe`

> Mac 如果提示「无法验证开发者」：右键点 app → 按住 Option 键 → 点「打开」即可

浏览器会自动弹出来，显示一个设置页面。

### 3. 填写 API Key
在设置页面填上管理员给你的 **DeepSeek API Key**，点「开始使用」。

> 这一步只需要做一次，以后打开直接进入系统。

## 日常使用

### 投简历（两种方式，任选其一）

**👇 方式一：网页上传**
打开系统页面，把简历文件拖进去就行。支持 PDF、Word、图片。

**👇 方式二：放文件夹**
把 PDF / Word 简历文件放到你的**下载文件夹**里（就是浏览器下载东西保存的地方），系统会自动发现、自动评估。

> 图片简历（JPG/PNG）的 OCR 识别需要额外安装软件。如果只用 PDF/Word，无需任何额外安装。

### 查看结果
简历评估完成后（一般 10-60 秒），页面会自动更新。你会看到：
- 综合评分（百分制）
- 各维度得分和评语
- 亮点 & 风险点
- 面试建议

### Pipeline 管理
页面左侧有四个阶段看板：
- **待筛选** → 简历放进来就在这里
- **面试中** → 拖到这里表示安排面试了
- **已通过** → 面试通过
- **已淘汰** → 不合适

拖拽卡片即可切换阶段。

## 常见问题

**关了浏览器系统还跑吗？**
还在跑。想再打开的话，浏览器访问 http://127.0.0.1:18980

**想改评分标准？**
系统里点「评估标准」，可以编辑各个岗位的维度和权重。

**想添加新岗位？**
在 config.yaml 文件里按示例格式添加。或找管理员帮忙。

**怎么关掉系统？**
Mac：右键 Dock栏的图标 → 退出
Windows：右键任务栏图标 → 关闭
