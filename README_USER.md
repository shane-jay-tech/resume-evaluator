# 简历评估系统 — 使用指南

---

## Mac 用户

### 安装（只需做一次）
1. 解压 ZIP 文件
2. 把 **`启动系统.command`** 拖到桌面
3. 双击桌面的 `启动系统.command` → 浏览器自动打开

> 如果提示「无法验证开发者」：右键点文件 → 打开 → 仍要打开

### 以后每次使用
双击桌面的 `启动系统.command`

---

## Windows 用户

### 安装（只需做一次）
1. 解压 ZIP 文件
2. 双击 **`install.bat`**
3. 桌面出现「简历评估系统」图标

### 以后每次使用
双击桌面的「简历评估系统」图标

---

## 首次设置

第一次打开时浏览器会显示配置页面：
1. 填 **DeepSeek API Key**（找管理员要）
2. 点「开始使用」

以后打开直接进入系统，不用再配置。

---

## 投简历

**网页上传**：打开系统页面，把简历 PDF/Word 文件拖进去

**文件夹投喂**：把简历文件放到**下载文件夹**，系统自动发现

评估完成后页面自动更新（一般 10-60 秒）。

---

## 常见问题

**关了浏览器还能用吗？**
系统在后台运行。重新打开浏览器访问 http://127.0.0.1:18980

**怎么关掉？**
Mac：右键 Dock 里 Python 图标 → 退出
Windows：右键任务栏图标 → 关闭窗口

**要改评分标准？**
系统里点「评估标准」→ 编辑 → 保存

**电脑没联网能用吗？**
可以。页面资源已全部内置，不依赖外部网络；只有 AI 评估本身需要联网调用 API。

**不想每次启动都自动打开浏览器？**
打开 config.yaml，把 server 下的 auto_open_browser 改成 false。

**启动时不想自动处理下载文件夹里的旧简历？**
把 config.yaml 里 monitor 下的 auto_process_existing 改成 false，旧文件就不会被自动评估，只处理之后新放进来的简历。
